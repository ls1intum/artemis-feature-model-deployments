# artemis-feature-model-deployments

Deployment repository of the Artemis Feature Model, created from
[artemis-feature-model-deployment-template](https://github.com/ls1intum/artemis-feature-model-deployment-template).
The template's README is the administrator guide: how publishing works, the GitHub Environment of each target, and
how to take over template changes.

Published packages live on the `deployment` branch under `deployments/<target>/package/`. The target `chair-vm`
deploys inside the GitHub Environment `chair-vm`.
